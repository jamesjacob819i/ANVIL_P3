Stage 5: Remediation Agent (2-3 seconds)

└─ Prepares PR

Stage 6: Deployment Agent (2-3 seconds)

└─ Monitors deployment

Stage 7: Postmortem Agent (2-3 seconds)

└─ Identifies learnings
